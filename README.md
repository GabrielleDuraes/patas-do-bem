# ONG Patas do Bem

Projeto acadêmico de front-end desenvolvido para simular o site de uma ONG de proteção animal.

## Sobre o projeto

O site apresenta informações sobre a ONG, formas de contribuição, animais disponíveis para adoção e cadastro de voluntários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SweetAlert2
- Git e GitHub

## Funcionalidades

- Página institucional da ONG
- Área de projetos e doações
- Cadastro de voluntários
- Validação de formulários
- Sistema de favoritos
- Armazenamento com LocalStorage
- Mensagens com SweetAlert2
- Layout responsivo

## Estrutura do projeto

O projeto está organizado nas pastas:

- `html` — páginas da aplicação
- `css` — estilos
- `js` — funcionalidades JavaScript
- `imagens` — imagens utilizadas no site

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Acesse a pasta `html`.
4. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou executar comandos de build.

## Versionamento

O projeto utiliza GitFlow com as branches:

- `main` — versão estável
- `develop` — desenvolvimento
- `feature/javascript` — desenvolvimento de funcionalidades JavaScript

A primeira versão estável foi publicada como `v1.0.0`.
